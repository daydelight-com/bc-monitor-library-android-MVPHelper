# Modifications

This repository contains a modified version of [MVPHelper](https://github.com/stfalcon-studio/MVPHelper)
(Copyright 2017 stfalcon.com), which is licensed under the Apache License, Version 2.0.
See [LICENSE](LICENSE) for the full license text.

The modifications were made by Day Delight Inc. in 2020, based on commit `1e60a39` of the original
repository, and are released as the tags `3.0.0` to `3.0.3`.

## Summary of changes

- Migrated the library from the Android Support Library to AndroidX.
- Updated the build configuration (Android Gradle Plugin, Kotlin, SDK versions and dependencies).
- Disabled publishing to Bintray and enabled building with JitPack.
- Updated the Gradle Wrapper.
- Removed the sample application.

## Modified files

Each of the following files carries a notice describing its changes at the top of the file.

| File | Changes |
|---|---|
| `mvphelper/src/main/java/com/stfalcon/mvphelper/MvpActivity.kt` | AndroidX migration, `LoaderManager.getInstance()`, nullability of `onCreateLoader()` |
| `mvphelper/src/main/java/com/stfalcon/mvphelper/MvpFragment.kt` | AndroidX migration, `LoaderManager.getInstance()`, nullability of `onCreateView()` / `onCreateLoader()` |
| `mvphelper/src/main/java/com/stfalcon/mvphelper/PresenterLoader.kt` | AndroidX migration |
| `mvphelper/build.gradle` | SDK versions, AndroidX / Dagger dependencies, `api` / `kapt` configurations, JitPack build |
| `build.gradle` | Android Gradle Plugin, Kotlin, repositories, JitPack build |
| `gradle.properties` | Enabled AndroidX |
| `.gitignore` | Stopped ignoring the Gradle Wrapper JAR |

The following files are generated by Gradle and were replaced with a newer version of the Gradle Wrapper,
so they do not carry an in-file notice:

- `gradlew`, `gradlew.bat` (updated)
- `gradle/wrapper/gradle-wrapper.jar`, `gradle/wrapper/gradle-wrapper.properties` (added)

## Removed files

- `sample/` (the sample application of the original repository)
